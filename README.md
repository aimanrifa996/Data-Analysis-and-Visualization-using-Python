# Data Analysis and Visualization using Python

## Project Overview
This project demonstrates data analysis and visualization using Python libraries: Pandas, NumPy, and Matplotlib.

## Dataset
Iris Flower Dataset.

## Tasks Completed
- Loaded and explored the Iris dataset.
- Examined dataset dimensions, columns, and statistical information.
- Checked and handled missing values and duplicate records.
- Performed data analysis using Pandas and NumPy.
- Calculated averages, minimums, maximums, and correlations.
- Created visualizations using Matplotlib.

## Visualizations
1. Bar Chart – Average Sepal Length by Species.
2. Line Chart – Sepal Length of First 30 Flowers.
3. Pie Chart – Distribution of Flower Species.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook

## Project File
`data_analysis.ipynb`

## Conclusion
Successfully completed data loading, exploration, cleaning, analysis, and visualization using Python.
